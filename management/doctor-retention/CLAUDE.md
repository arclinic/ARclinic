**ВАЖНО: При открытии этой папки ТЫ ДОЛЖЕН НЕМЕДЛЕННО, БЕЗ ОЖИДАНИЯ КОМАНДЫ ПОЛЬЗОВАТЕЛЯ, запустить быструю проверку возвращаемости:**

```bash
python ../../.claude/skills/management/scripts/doctor_retention.py weekly --output-dir reports
```

После выполнения выведи результат: если есть алерты — покажи их. Если скрипт промолчал — напиши «Все врачи в норме, алертов нет».

Затем сообщи пользователю доступные команды: `собери полный отчёт` (monthly), `обнови данные` (--force-refresh), `на дату X`.

## Агент
**Файл:** `../../.claude/skills/management/scripts/doctor_retention.py`

### Режимы

**monthly** — полный XLSX-отчёт (1-го числа каждого месяца):
```bash
python ../../.claude/skills/management/scripts/doctor_retention.py monthly --output-dir reports
```
5 листов: Сводка, Рейтинг, Тренды, Перетекание, Прогноз.
XLSX сохраняется в `doctor-retention/reports/retention-YYYY-MM-DD.xlsx`.

**weekly** — быстрая проверка (по понедельникам):
```bash
python ../../.claude/skills/management/scripts/doctor_retention.py weekly --output-dir reports
```
Если врач ниже среднего → алерт. Если всё в норме → молчит.

### Аргументы
```
--date YYYY-MM-DD     отчёт на конкретную дату
--force-refresh       сбросить кеш и перезапросить API
--output-dir DIR      куда класть XLSX (по умолчанию reports)
```

## Что считает
- **Rate A** — возврат к тому же врачу (3/6/9/12 мес)
- **Rate B** — возврат в клинику к любому врачу
- **Перетекание D** — матрица врач→врач (кто к кому уводит)
- **Тренды** — динамика за 6 периодов
- **Прогноз** — загрузка и выручка на следующий месяц

## Метрики и пороги
| Цвет | Условие |
|------|---------|
| Зелёный | Rate A ≥ среднего по клинике при ≥10 первичных |
| Красный | Rate A < среднего по клинике при ≥10 первичных |
| Жёлтый | <10 первичных (статистически незначимо) |
