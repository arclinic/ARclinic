# Управление клиникой ARclinic — Django-приложение

Этот файл — точка входа для AI-сессии в папке `management/`. Здесь находится Django-приложение «Управление» и подпроекты аналитики.

## Структура
- `doctor-retention/` — проект «Возвращаемость пациентов» (отдельный workspace, открывать как самостоятельную папку)
- `client-segmentation/` — проект «Сегментация клиентов» (отдельный workspace)
- `models.py`, `views.py`, `urls.py` — Django-приложение управления
- `operator_report.py` — отчёты операторов (устарел, использовать v3)
- `operator_report_v3.py` — **актуальный** отчёт по операторам: лиды из чатов, конверсия, скорость ответа + лист «Клиника» со статистикой сделок
- `leads_no_source.py` — список лидов без источника (SOURCE_ID=67) со ссылками на карточки
- `unassigned_leads.py` — лиды на техаккаунтах (не проставлен оператор)
- `resolve_names.py` — утилита: резолвинг имён пользователей через tasks.task.get
- `tasks.py` — Celery-задачи

## Агенты аналитики
Все агенты находятся в отдельных подпапках со своим `CLAUDE.md`:
- `doctor-retention/` — возвращаемость пациентов к врачам (открыть как отдельный проект)
- `prep-report/` — отчёт по препаратам: группировка сделок по врачам с фильтром по товару (открыть как отдельный проект)
- `client-segmentation/` — сегментация клиентов: матрица переходов, реактивация, новые пациенты (открыть как отдельный проект)

## Сегментация клиентов
Скрипты сегментации клиентов по сделкам Bitrix24:
- `client_segmentation_transition.py` — матрица переходов между сегментами за месяц (с кэшем)
- `transition_report_may.py` — форматированный отчёт по переходам
- `list_lost_to_dev_16.py` — список реактивированных клиентов со ссылками на карточки
- `client_segmentation_cache.json` — кэш сделок (перестроить при изменении методологии)

### Правила сегментации
- **Дата визита**: поле `UF_CRM_1738231866` (дата и время записи), fallback: `BEGINDATE`, затем `DATE_CREATE`
- **Учитывать**: только сделки на стадии `C1:WON` (Приём окончен). NEW, PREPARATION, APOLOGY, LOSE — исключены
- **История**: выборка с 01.01.2020 (для отделения первичных от потерянных)
- **Окно**: 365 дней от даты снимка
- Подробнее: `мозг_клиники_ARclinic/бизнес/сегментация.md`

## Команды AI
При работе в этой папке AI должен:
1. При запросах про возвращаемость → предложить открыть папку `doctor-retention/` как отдельный workspace
2. При запросах про отчёты по препаратам (Stylage, Белларти, др.) → предложить открыть папку `prep-report/` как отдельный workspace
3. При запросах про сегментацию клиентов → предложить открыть папку `client-segmentation/` как отдельный workspace
4. При запросах про Django-модели, миграции, админку → работать с `models.py`, `admin.py`
5. Не запускать агентов из этой папки — они живут в своих подпапках
