# Агент «Сегментация клиентов ARclinic»

**ВАЖНО: При открытии этой папки ТЫ ДОЛЖЕН НЕМЕДЛЕННО, БЕЗ ОЖИДАНИЯ КОМАНДЫ ПОЛЬЗОВАТЕЛЯ, запустить отчёт по переходам:**

```bash
python ../transition_report_may.py
```

После выполнения выведи результат: ключевые переходы (вверх / вниз / баланс). Если скрипт выдал ошибку — покажи её и предложи перестроить кэш.

Затем сообщи пользователю доступные команды: `матрица переходов`, `список реактивированных`, `проверить клиента`, `на дату X`.

## Агент
**Скрипты:** в `../` (папка `management/`)

### Команды

**Матрица переходов за месяц** (полный расчёт):
```bash
python ../client_segmentation_transition.py
```
Строит матрицу 4x4 (первичные / потерянные / развитие / постоянные), ключевые переходы, баланс. Использует `client_segmentation_cache.json`.

**Форматированный отчёт** (только вывод, без перестройки кэша):
```bash
python ../transition_report_may.py
```
Выводит отчёт в формате: вверх / вниз / баланс. Для смены месяца — отредактировать даты снимков в скрипте.

**Список реактивированных** (потерянные → развитие):
```bash
python ../list_lost_to_dev_16.py
```
Список клиентов со ссылками на карточки контактов.

**Проверить конкретного клиента:**
```bash
python -c "
from shared.bitrix24 import call;
r = call('crm.contact.get', {'id': ID});
print(r.get('result', {}).get('NAME'))
"
```

## Правила сегментации

| Сегмент | Критерий |
|---|---|
| Первичный | 0 сделок в окне 365 дней И 0 сделок до окна |
| Потерянный | 0 сделок в окне, но были сделки до окна |
| Развитие | 1–5 сделок в окне |
| Постоянный | >5 сделок в окне |

- **Дата визита:** `UF_CRM_1738231866` (дата и время записи), fallback: `BEGINDATE`, затем `DATE_CREATE`
- **Учитывать:** только сделки на стадии `C1:WON` (Приём окончен). NEW, PREPARATION, APOLOGY, LOSE — исключены
- **Выборка:** с 01.01.2020 для отделения первичных от потерянных
- **Кэш:** `../client_segmentation_cache.json` (24h, перестроить при смене методологии — `--force` или удалить файл)
- Подробнее: `../../мозг_клиники_ARclinic/бизнес/сегментация.md`

## Правила AI при работе в этой папке

1. «Отчёт по сегментации», «переходы за месяц» → `client_segmentation_transition.py`
2. «Список реактивированных», «кто вернулся из потерянных» → `list_lost_to_dev_16.py`
3. «Проверь клиента X» → API-запрос через `shared.bitrix24.call()`
4. «Собери отчёт» за конкретный месяц → изменить даты `snap_apr` и `snap_may` в `client_segmentation_transition.py`
5. При подозрении на ошибку классификации → проверить все сделки клиента через API без фильтра по дате
