# SEO-Aудит arclinic.ru

**Дата:** 28.05.2026
**Тип:** Медицинская клиника (косметология, антивозрастная медицина)
**CMS:** 1C-Bitrix

---

## Executive Summary

**Общая оценка: 52/100** — сайт имеет хорошую структуру и контент, но критические технические проблемы блокируют индексацию.

### Топ-5 критических проблем
1. Sitemap.xml ведёт на localhost — поисковики не видят страницы сайта
2. Нет Schema.org разметки (MedicalBusiness/LocalBusiness)
3. Title «ARclinic» без ключевых слов
4. Нет HSTS и security-заголовков
5. og:url использует http:// вместо https://

### Топ-5 быстрых побед
1. Исправить sitemap.xml (заменить localhost на arclinic.ru)
2. Добавить JSON-LD MedicalBusiness разметку
3. Расширить title («ARclinic — Центр антивозрастной медицины и косметологии в СПб»)
4. Исправить og:url на https://
5. Добавить robots meta noindex на служебные страницы

## 1. Технический SEO

### Sitemap.xml — КРИТИЧЕСКИ
```
<loc>http://localhost/sitemap_files.xml</loc>
<loc>http://localhost/sitemap_iblock_1.xml</loc>
...
```
Все 14 sub-sitemaps указывают на `http://localhost/` вместо `https://arclinic.ru/`. Яндекс и Google не могут по ним пройти.

### robots.txt — ХОРОШО
- Чётко прописаны disallow для битриксовых системных путей
- allow для /upload/, *.js, *.css
- Sitemap указан верно: `https://arclinic.ru/sitemap.xml`

### Security Headers — ПЛОХО
- HSTS: отсутствует
- X-Content-Type-Options: отсутствует
- X-Frame-Options: отсутствует
- Content-Security-Policy: отсутствует
- Server: nginx-reuseport/1.21.1 (информация версии утекает)
- X-Powered-By: PHP/8.1.32 (информация версии утекает)
- Cache-Control: no-store (отключает кеширование)

### Open Graph
- og:url: `http://arclinic.ru/` (должен быть https)
- og:image: favicon 96x96 (слишком маленький)
- og:title: «ARclinic» (слишком короткий)

### Core Web Vitals — НЕ ИЗМЕРЕНО
Требуются данные Google CrUX. Рекомендуется настроить Google Search Console.

## 3. Schema.org / Structured Data — КРИТИЧЕСКИ

**JSON-LD не обнаружена.** На сайте нет никакой Schema.org разметки.

Что необходимо добавить:
- **MedicalBusiness** (или LocalBusiness) — адрес, телефон, часы работы, геокоординаты
- **Physician** — для каждого врача
- **MedicalProcedure** — для каждой услуги
- **MedicalSpecialty** — косметология, гинекология, дерматология и т.д.
- **AggregateRating** — отзывы с рейтингом
- **BreadcrumbList** — навигационная цепочка
- **WebSite** — SearchAction для поиска по сайту
