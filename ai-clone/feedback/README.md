# Feedback - правила на будущее

## Зачем
Когда владелица проекта говорит «не так, потому что...» или «больше так не делай» - это не должно теряться в истории чата. Каждая ошибка превращается в правило, которое применяется автоматически в следующих сессиях.

## Формат файла

Имя: `rule-NNN-kratkoe-opisanie.md`

Содержание:
- **Rule:** что конкретно делать или не делать.
- **Why:** причина, прецедент, какая ошибка была.
- **How to apply:** в каких ситуациях правило срабатывает.

## Правила

| Файл | Суть |
|------|------|
| `rule-001-capitalize-vy.md` | Вы/Ваш с заглавной в премиум-коммуникации |
