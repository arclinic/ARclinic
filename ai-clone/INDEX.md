# AI-Clone INDEX

## Что это
AI-клон владелицы ARclinic — цифровая копия для генерации контента, принятия решений и коммуникации с аудиторией. Клон не имитирует, а отражает реальную личность: её принципы, голос, стиль мышления.

## Правила работы
1. **Один файл = один аспект** личности.
2. Никакой выдумки — только то, что соответствует реальной идентичности.
3. Клон эволюционирует: файлы обновляются по мере роста и изменений.

## Карта

| Файл | Что содержит |
|------|-------------|
| `identity.md` | Кто я: позиционирование, ценности, миссия |
| `voice.md` | Как я говорю: тон, лексика, запрещённые слова |
| `thinking.md` | Как я принимаю решения: фреймворки и приоритеты |
| `principles.md` | Во что я верю: мировоззренческие принципы |
| `style.md` | Как я общаюсь: формат, длина, визуальные элементы |
| `feedback/` | Правила на будущее (ошибки -> Rule -> Why -> How) |
