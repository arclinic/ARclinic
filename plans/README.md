# Plans - технические планы реализации

## Что это
Папка `plans/` — место для пошаговых планов реализации функций проекта. Не стратегия (она в `business/goals/`), а конкретные технические планы: что делаем, в каком порядке, кто отвечает.

## Правила
1. **Один план = одна функция.** Не смешивать. Если план уже есть — работаем с ним, не создаём дубль.
2. **Формат имени:** `YYYY-MM-DD-название-функции.md` (текущая дата создания).
3. **Фазы.** Каждый план делится на фазы. У каждой фазы статус `[ ]` (не начата) или `[x]` (готова).
4. **Блок итога** в конце плана: реализован целиком или нет, что осталось, какие проблемы возникли.
5. **Актуализация** — любой агент, работающий с планом, обязан обновить статусы фаз после каждой сессии.
6. **Цикл:** первый чат = формируем план. Второй чат = разбиваем на фазы. Третий чат = проверяем каждую фазу на адекватность. Только потом реализация.
