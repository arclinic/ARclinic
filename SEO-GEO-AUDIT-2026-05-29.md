## 1. КРИТИЧЕСКИЕ (исправить немедленно)

### 1.1 Sitemap захламлён dev-файлами (CRITICAL)
- `sitemap_000.xml` содержит ~70+ URL из `node_modules/` (gulp, browser-sync, weinre, fsevents, и т.д.)
- Это **растрата краулингового бюджета** Googlebot
- Также присутствуют: `/instafeed/`, `/search/`, `/about/video/`, `/about/reviews.php`, `/blog/index2.php`
- **Фикс:** Регенерировать sitemap, исключив:
  - `/node_modules/*`
  - `/search/`
  - `/instafeed/`
  - Страницы с `.php` расширением (где есть clean URL-альтернатива)
  - Дубли: `/otzyv/` дублирует `/reviews/`

### 1.2 JSON-LD Schema пустой (CRITICAL)
- `<script type="application/ld+json">` на главной не содержит данных
- **Нет:**
  - `LocalBusiness` schema (адрес, телефон, часы работы)
  - `MedicalBusiness` schema (для медицинских услуг)
  - `Organization` schema (соцсети, логотип)
  - `Person` schema (для врачей)
- **Фикс:** Добавить schema.org разметку для медицинской организации

### 1.3 Блог недоступен (CRITICAL)
- `https://arclinic.ru/blog/` — HTTP 000 (не отвечает)
- Статьи и блог — ключевой контент для E-E-A-T и GEO
- **Фикс:** Проверить настройки сервера/раздела блога
