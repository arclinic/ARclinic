# VK API — статус и инструкция

## Что есть сейчас (проверено 13.08.2026)

| Переменная | Тип токена | Что умеет |
|---|---|---|
| `VK_ACCESS_TOKEN` | Сервисный | Только методы без прав юзера |
| `VK_USER_TOKEN` | **Групповой** (не юзерский!) | Только `groups.getById`. Ошибка 27 на wall.get / market.get / account.* |

**Вывод:** оба токена НЕ позволяют читать стену и товары группы. Нужен **пользовательский токен** (от аккаунта **«Арклиник»**, который админ группы).

## Как получить пользовательский токен

**Важно:** токен должен быть получен от аккаунта **«Арклиник»** — именно он админ группы ARclinic (Юлия — личный аккаунт, прав на группу нет).

**Способ 1 — vkhost.github.io (БОЛЬШЕ НЕ РАБОТАЕТ):**
Сервис заблокирован: `{"error":"invalid_request","error_description":"application is blocked"}`. Не использовать.

**Способ 2 — официальный, через собственное приложение VK (работает всегда):**

1. Залогинься в VK как аккаунт **«Арклиник»** (админ группы)
2. Создай приложение: https://vk.com/editapp?act=create
   - Название: любое (например «ARclinic API»)
   - Платформа: **Standalone-приложение** (важно!)
3. Открой https://vk.com/apps?act=manage — скопируй **ID приложения** (число, например 51712345)
4. Подставь ID в ссылку и открой её (замени 51712345):
   ```
   https://oauth.vk.com/authorize?client_id=51712345&display=page&redirect_uri=https://oauth.vk.com/blank.html&scope=wall,market,groups,photos,offline&response_type=token&v=5.199
   ```
5. VK покажет список разрешений → **Разрешить**
6. Откроется пустая страница blank.html. В адресной строке будет:
   `https://oauth.vk.com/blank.html#access_token=vk1.a.XXX...&expires_in=0&user_id=...`
7. Скопируй всё после `access_token=` до `&expires_in` — это и есть токен

**Важно:** параметр `scope=...offline` даёт бессрочный токен. Без него токен умрёт через несколько часов.

## Что класть в .env

```
VK_USER_TOKEN=vk1.a.XXX...
```

Проверка токена после получения:
```python
api('wall.get', {'owner_id': -56956529, 'count': 1})  # должен вернуть посты
```

## Что даст юзерский токен

- Чтение стены ARclinic (wall.get)
- Чтение товаров ARclinic (market.get — 100+ позиций косметики)
- Чтение стен конкурентов (wall.get с их owner_id/domain)
- Аналитика постов конкурентов: частота, форматы, вовлечённость
- Автопостинг в VK (уже реализован в marketing/smm/auto_poster.py)
