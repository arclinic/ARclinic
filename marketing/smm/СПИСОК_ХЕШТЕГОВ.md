## Логика построения

Для каждой процедуры хэштег-сетка строится по формуле:

```
процедура → проблема → аппарат/препарат → результат → зона → бренд
```

Пример для ICOONE LASER: `#icoone #icoonelaser #липолиз #лимфодренаж #целлюлит #коррекцияфигуры #laserlipolysis`

Правила:
- База всегда: `#arclinic` `#спб`
- Широкие + узкие: 2-3 высокочастотных + 2-3 нишевых
- Бренд аппарата/препарата — обязательно при демонстрации процедуры
- Запрещено: `#москва`, `#москвасити`, любые московские гео-теги
- Макс 10 на пост Instagram, 3-5 на Reels/Stories
- Регистр: нижний для русского, CamelCase для англ. названий (`#VirtueRF`, `#SmartXide2`)
