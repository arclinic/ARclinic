# Шаблоны контента для ARclinic SMM

## Reels (30-40 секунд)

### Структура
```
[0:00-0:05] HOOK — захват внимания
[0:05-0:15] BODY — раскрытие темы
[0:15-0:30] VISUAL — визуал (процедура / фото / схемы)
[0:30-0:35] CTA — призыв к действию
```

### Формула подписи
```
Заголовок-хук (1 предложение)

3-5 фактов / пунктов
с эмодзи или маркерами

Призыв к действию — запись, комментарий, сохранение

#arclinic #арклиникспб [3-5 тематических]
```

### Тон
- Как с подругой — честно, без заумных терминов
- С юмором там, где уместно
- Короткие предложения
- Один Reels = одна мысль

## Пост (Instagram / VK)

### Типы постов

**Образовательный:**
```
Заголовок-вопрос или заголовок-утверждение

Абзац 1: Контекст / миф / проблема
Абзац 2: Объяснение (простое, без терминов)
Абзац 3: Решение / рекомендация
Абзац 4: CTA + хештеги
```

**До/После:**
```
Заголовок: "ДО и ПОСЛЕ: [процедура]"

Фото до → проблема
Процесс → как решали
Фото после → результат
Текст: детали (срок, количество процедур, врач)

Пометка: "Результат индивидуален, требуется консультация врача"

CTA + хештеги
```

**Карусель:**
```
Слайд 1: Обложка — заголовок
Слайд 2-4: Контент — факты / советы / шаги
Слайд 5: CTA — запись / ссылка
```

## Telegram (канал @arclinic1)

### Формат
- Длиннее Instagram (до 4096 символов)
- Можно развёрнутые объяснения
- Минимум эмодзи (1-2 на пост)
- Ссылки на сайт / запись в конце

### Шаблон
```
Заголовок: **жирным**

Текст. Развёрнутое объяснение процедуры, мифа, подхода.

**Главная мысль** — выделить жирным.

В ARclinic мы [подход / отличие].

Запись: [ссылка]

#arclinic
```

## Stories (Instagram)

### Серия из 5 слайдов
```
Слайд 1 (HOOK):   Вопрос / заголовок / интрига
Слайд 2 (VALUE):  Основная мысль / факт
Слайд 3 (VALUE):  Дополнение / пример
Слайд 4 (PROOF):  Доказательство (фото / видео / цифры)
Слайд 5 (CTA):    "Запись в Direct" / опрос / реакция
```
