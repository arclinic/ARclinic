## 2. Critical Issues (блокируют ранжирование)

### CRIT-1: Meta descriptions отсутствуют на ВСЕХ подстраницах
**Где:** /doctors/, /services/, /about/, /contacts/, /blog/, /prices/, /news/, все сервисные страницы (~95+), все страницы врачей.

**Проблема:** Google не показывает сниппет в выдаче, резкое падение CTR. Единственная страница с meta description - главная.

**Исправление:** Добавить meta description на каждую страницу (150-160 символов, с ключевыми словами и призывом к действию).

| Страница | Рекомендуемый meta description |

### CRIT-2: Title теги критически короткие на подстраницах
**Где:** Все подстраницы, кроме главной.

**Проблема:** Title в 1-2 слова ("Специалисты", "Услуги", "О клинике", "Блог", "Контакты") без названия клиники и города. Это прямо влияет на ранжирование.

**Исправление:** Title должен быть 50-60 символов, включать бренд + город + ключевую фразу.

| Страница | Текущий title | Рекомендуемый title |
|---|---|---|
| /doctors/ | Специалисты | Врачи ARclinic в СПб - команда косметологов и anti-age специалистов |
| /services/ | Услуги | Услуги антивозрастной медицины в ARclinic - косметология и чекапы в СПб |
| /about/ | О клинике | О клинике ARclinic - центр anti-age медицины в Санкт-Петербурге |
| /contacts/ | Контакты | Контакты ARclinic в Санкт-Петербурге - адрес, телефон, запись |
| /blog/ | Блог | Блог ARclinic - anti-age медицина, косметология, здоровье в СПб |
| /prices/ | Наши цены | Цены на услуги ARclinic в СПб - стоимость консультаций и процедур |

### CRIT-3: Массовое отсутствие alt-текстов у изображений
**Где:** Все страницы сайта.

**Проблема:**
- Сервисные страницы: 87/89 (98%) без alt
- Страницы врачей: 131/145 (90%) без alt
- Список врачей: 19/21 (90%) без alt
- Список услуг: 27/29 (93%) без alt

Это критично для:
1. Ранжирования в Google Images
2. Доступности (слепые пользователи)
3. E-E-A-T сигналов (Google учитывает доступность)

**Исправление:** Добавить alt-тексты ко всем изображениям. Примеры для типовых изображений:

| Тип изображения | Alt-текст |
|---|---|
| Фото врача | Врач-косметолог ARclinic [имя] на приёме в клинике на Верейской |
| Фото клиники (особняк) | Особняк ARclinic 1884 года на улице Верейской в Санкт-Петербурге |
| Результат процедуры | Результат ботулинотерапии в ARclinic - коррекция мимических морщин |
| Аппарат | Аппарат Ultraformer III для SMAS-лифтинга в клинике ARclinic |
| Интерьер кабинета | Кабинет центра антивозрастной медицины ARclinic в СПб |

### CRIT-4: Нет заголовков безопасности
**Проблема:** Отсутствуют HSTS, X-Frame-Options, X-Content-Type-Options, Content-Security-Policy, Referrer-Policy.

**Исправление (в конфигурацию nginx):**

```nginx
add_header X-Frame-Options "SAMEORIGIN" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Permissions-Policy "geolocation=(), microphone=(), camera=()" always;
```

## 3. High Impact Issues

### HIGH-1: Schema-разметка только на главной
**Проблема:** MedicalBusiness schema есть только на главной. На сервисных страницах, страницах врачей и в блоге структурированные данные отсутствуют.

### HIGH-2: Версия PHP и nginx открыты
**Проблема:** Заголовки Server и X-Powered-By раскрывают версии (PHP/8.1.32, nginx-reuseport/1.21.1). Это информация для атакующих.

**Исправление:**
```nginx
server_tokens off;
```
И в php.ini: `expose_php = Off`

### HIGH-3: 6 скриптов Marquiz на каждой странице
**Проблема:** 6 отдельных скриптов чата Marquiz загружаются на каждой странице. Это существенно влияет на Core Web Vitals (LCP, INP).

**Исправление:** Объединить в один скрипт или использовать условную загрузку только при взаимодействии пользователя.

### HIGH-4: Google Search Console не настроена
**Проблема:** На сайте обнаружен Yandex Webmaster, но нет Google Search Console. Нельзя отслеживать позиции в Google, индексные статусы, ошибки краулинга.

**Исправление:** Добавить meta-тег верификации Google Search Console в `<head>`:
```html
<meta name="google-site-verification" content="ВАШ_КЛЮЧ_ВЕРИФИКАЦИИ">
```

### HIGH-5: Cache-Control: no-store
**Проблема:** Браузеры не кешируют страницы, что увеличивает время загрузки при повторных визитах.

**Исправление:** Настроить кеширование для статических ресурсов и HTML-страниц:
```
Cache-Control: public, max-age=3600, must-revalidate
```

## 8. Рекомендации по контенту для AI Overviews

**Текущее состояние (GEO): 75/100**

**Что уже хорошо:**
- llms.txt присутствует и хорошо структурирован (59 строк, полная карта сайта)
- AI-краулеры разрешены в robots.txt (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot)
- RSL-лицензия (CC BY-NC 4.0) объявлена
- Контент сервисных страниц 2000+ слов - достаточный объём
- GA4 подключён (данные для поисковых систем)

**Что улучшить:**
1. **Прямые ответы в начале абзацев** - переписать введение на сервисных страницах в формате "Ботулиноторпия в ARclinic - это процедура коррекции мимических морщин препаратами ботулотоксина. Процедура занимает 15-20 минут, эффект сохраняется 4-6 месяцев."

2. **FAQ-структура** - добавить блок FAQ на каждую сервисную страницу с вопросами (как проходит процедура, сколько держится, есть ли противопоказания, как подготовиться). Это напрямую цитируется AI-поисковиками.

3. **Пассажи по 134-167 слов** - разбить контент на самодостаточные смысловые блоки, каждый из которых отвечает на один конкретный вопрос. AI Overviews цитирует пассажи именно такого объёма.

4. **Авторство** - добавить указание автора на статьи в блоге (Article schema + авторство). Это ключевой сигнал E-E-A-T для AI.

5. **Статистика и исследования** - добавить ссылки на исследования, данные и цифры (например, "по данным исследования 2024 года, эффективность ботулинотерапии при мигрени составляет 87%"). AI-поисковики предпочитают контент с фактами.

6. **Отзывы пациентов с цитатами** - AI Overviews часто цитирует реальные отзывы при ответе на запросы "стоит ли делать X".
