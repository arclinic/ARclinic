## Задача — выполнить по порядку

### Этап 1. Meta-теги для главных страниц (15 мин)
Сгенерируй готовые `<title>` и `<meta name="description">` для страниц:
- `/doctors/` — список специалистов
- `/services/` — список услуг
- `/about/` — о клинике
- `/contacts/` — контакты
- `/blog/` — блог
- `/prices/` — цены

Формат выдачи: таблица URL | Title | Meta Description. В title обязательно: ключевая фраза + "ARclinic в СПб".

### Этап 2. Schema.org — готовый JSON-LD (30 мин)
Сгенерируй готовый JSON-LD для вставки в Bitrix:

2a. **MedicalService** для трёх топ-услуг:
- Ботулинотерапия (/services/cosmetology/injection/botulinoterapiya/)
- Контурная пластика (/services/cosmetology/injection/konturnaya-plastika/)
- Чекапы (/services/health-center/chek-apy/)

2b. **FAQPage** для этих же трёх страниц (по 3 вопроса-ответа).

2c. **Physician** для страниц врачей (на примере Дроздовой Анны Андреевны).

2d. **Article** для блога (универсальный шаблон).

### Этап 3. Twitter Cards (15 мин)
Сгенерируй `<meta name="twitter:*">` теги для вставки в `<head>`. Базовые данные взять из OG-тегов.

### Этап 4. HTML-исправления для Bitrix (30 мин)
На основе `SEO-AUDIT-FULL-REPORT.md` (раздел 5) проверь alt-тексты:

4a. Главная страница — напиши alt для 5 изображений без alt (проверь `arclinic_homepage.html` в папке).

4b. `/doctors/` — напиши alt для 19 изображений врачей (проверь `arclinic_doctors.html`).

4c. `/services/` — напиши alt для 27 изображений услуг (проверь `arclinic_services.html`).

### Этап 5. Stale-страницы
Прочитай `arclinic_sitemap_000.xml`. Найди страницы с lastmod до 2024 года. Дай рекомендации:
- Какие оставить и обновить
- Какие удалить из sitemap (instafeed, reviews.php, etc.)
- Как настроить автообновление lastmod в Bitrix

### Этап 6. Финальный чек-лист
Выдай готовый `<head>` для одной страницы (ботулинотерапия), собрав ВСЁ вместе:
- `<title>` оптимизированный
- `<meta name="description">`
- `<meta name="twitter:*">` все
- `<link rel="canonical">`
- ДВА `<script type="application/ld+json">`: MedicalService + FAQPage
- Все `<meta property="og:*">`

Это будет шаблон, который можно скопировать в шаблон Bitrix.
