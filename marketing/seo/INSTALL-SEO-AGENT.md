# Установка SEO-агента для OpenCode

## Что в архиве

```
seo-agent/
├── .opencode/
│   ├── agent/              (4 субагента: technical, content, schema, geo)
│   └── skills/             (5 навыков + reference-файлы)
├── scripts/
│   └── seo/                (3 Python-скрипта: fetch, schema, pagespeed)
├── opencode.json.example   (шаблон конфигурации)
├── requirements.txt        (Python-зависимости)
├── INSTALL.md              (этот файл)
└── PROMPT.txt              (промт для запуска SEO-сессии)
```

## Пошаговая установка

### Шаг 1. Найдите рабочую папку проекта

Откройте терминал и перейдите в папку проекта:

```powershell
cd "путь\к\папке\проекта"
```

### Шаг 2. Проверьте наличие папки "мозг"

Папка "мозг" содержит источники истины (о клинике, услугах, контент-принципах).
Если она уже есть в проекте - отлично. Если нет - уточните у руководителя где она находится.

Структура папки "мозг":
```
мозг/
├── CLAUDE.md                  (общая инструкция по проекту)
├── бизнес/
│   ├── клиника.md             (информация о клинике и врачах)
│   └── услуги.md              (основные услуги)
└── идентичность/
    └── контент-принципы.md    (правила создания контента)
```

### Шаг 3. Скопируйте файлы агента

Скопируйте содержимое архива в корень проекта:

**Windows (Explorer):**
1. Откройте архив zip
2. Перетащите папки `.opencode` и `scripts` в корень проекта
3. Если спросит "заменить файлы?" - нажмите "Да"

**PowerShell:**
```powershell
Expand-Archive -Path "seo-agent.zip" -DestinationPath "." -Force
```

### Шаг 4. Настройте конфигурацию

Скопируйте шаблон конфигурации:

```powershell
Copy-Item "opencode.json.example" "opencode.json"
```

Откройте `opencode.json` и вставьте ваш API-ключ вместо `ВСТАВЬТЕ_СЮДА_ВАШ_API_КЛЮЧ`.

**Если у вас уже есть opencode.json** - добавьте в него секцию `"skills"`:

```json
{
  "skills": {
    "paths": [".opencode/skills"]
  }
}
```

### Шаг 5. Установите Python-зависимости

```powershell
pip install -r requirements.txt
```

Или вручную:

```powershell
pip install requests beautifulsoup4 lxml
```

### Шаг 6. Проверьте установку

Запустите OpenCode в папке проекта:

```powershell
opencode
```

В сессии введите:

```
seo audit https://arclinic.ru
```

Если агент работает корректно - вы увидите SEO-отчёт.

## Стиль текста

- Доказательная медицина, экспертный тон
- БЕЗ фамилий врачей - только специальности
- БЕЗ длинных тире (—), использовать дефис (-)
- Русские кавычки "" вместо «»
- Оптимизация под AI Overviews и голосовой поиск

## Решение проблем

| Проблема | Решение |
|----------|---------|
| `ModuleNotFoundError: requests` | `pip install requests beautifulsoup4 lxml` |
| `opencode: command not found` | Установите OpenCode: https://opencode.ai |
| PageSpeed API 429 | Пропустите секцию CWV - агент это обрабатывает |
| Агент не запускается | Проверьте наличие `.opencode/skills/seo/SKILL.md` |
