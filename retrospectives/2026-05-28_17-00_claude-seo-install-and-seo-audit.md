# Ретроспектива: 2026-05-28

## Какая задача была поставлена
1. Установить claude-seo (репозиторий AgriciDaniel/claude-seo)
2. Зарегистрироваться на Apify и установить Instagram Scraper
3. Провести SEO-аудит arclinic.ru и исправить проблемы

## Как я решал
- Пытался клонировать репозиторий claude-seo через git — DNS нестабилен (github.com то доступен, то нет)
- Изначально `pip install claude-seo` — не находит пакет
- `git clone` с `--depth 1` и длинным таймаутом — сработал с 3-й попытки
- `webfetch` GitHub — сработал, получил полную информацию о репозитории
- `webfetch` arclinic.ru — получил HTML homepage, about, contacts, doctors, services
- DNS проблема системная: 8.8.8.8 не отвечает, 1.1.1.1 тоже, но кэш иногда спасает
- curl.exe работал лучше, чем Invoke-RestMethod (другой DNS-резолвер)
- Установка claude-seo через install.ps1 — выполнена, 25 sub-skills на месте
- Python-зависимости не встали из-за таймаутов PyPI
- Playwright не установился
- SEO-аудит провёл через webfetch + анализ HTML, без Python-скриптов
- Аукдит сохранён в seo-audit-arclinic.md
- План исправлений сохранён в plans/seo-fixes-arclinic.md
- Открыл Bitrix-админку, пользователь залогинилась, но сессию прервали

## Решил ли
Частично
- Claude SEO — установлен, все навыки на месте
- Apify — аккаунт создан, API-ключ получен и проверен, Instagram Scraper доступен
- SEO-аудит — проведён, отчёт готов
- Правки на сайте — не внесены (пользователь отложила на завтра)

## Эффективно ли решение, что можно было лучше
- DNS-проблемы съели много времени. Надо было сразу пробовать curl.exe вместо Invoke-RestMethod
- Для будущих сессий: pip install можно делать с таймаутом побольше или через зеркало
- Аудит через webfetch + ручной анализ дал хороший результат, но Python-скрипты дали бы больше данных (CWV, Pagespeed)
