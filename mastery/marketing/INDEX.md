# Маркетинг — карта папки

**Правило:** Один файл = один автор. 1–3 метода из основного труда. Только прикладное, без пересказа биографии.

## Авторы

| Файл | Автор | Вклад |
|------|-------|-------|
| [[claude-hopkins]] | Клод Хопкинс | Научная реклама: тесты, конкретика, сервисный подход |
| [[david-ogilvy]] | Дэвид Огилви | Большая идея, правила заголовков, факты вместо имиджа |
| [[eugene-schwartz]] | Юджин Шварц | 5 уровней осознанности, механизм действия, желание vs потребность |
| [[john-caples]] | Джон Кэплз | Тестирование заголовков, длинный текст, результат на первое место |
| [[al-ries]] | Эл Райс | Позиционирование, лестница в сознании, сужение фокуса |

## Связи между методами

Все авторы дополняют друг друга:
- Хопкинс → Кэплз (тестирование) → Огилви (факты)
- Шварц (уровни осознанности) → Райс (позиционирование под каждый уровень)
