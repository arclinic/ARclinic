# Mastery — личный совет директоров

## Методология

**Один автор = один файл.** Берём у каждого гения только 1-2-3 его сильнейших метода, не пересказываем книги целиком. Только то, что можно применить.

Mastery отличается от Skills и Reference:

- **Skills** — инструкции для opencode-агентов (как выполнять задачи)
- **Reference** — шпаргалки по инструментам (как работает конкретная технология)
- **Mastery** — фреймворки мышления и методы работы великих людей (как принимать решения и действовать)

## Структура

```
mastery/
├── INDEX.md   — карта папки, список областей и правил
├── README.md  — эта методология
├── product/   — продуктовые методы (одна папка = одна область)
│   ├── marty-cagan.md
│   └── ...
├── code/      — методы разработки
├── business/  — бизнес-методы
├── strategy/  — стратегия
└── ...
```

Одна папка = одна область. Один файл = один автор.
