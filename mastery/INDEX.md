# Mastery INDEX

## Что это

Mastery — «личный совет директоров». Концентрат методов лучших умов мира по нужным мне областям. Не конспекты книг, а выжимка: **1-2-3 гениальных метода** от каждого автора, которые можно применить прямо сейчас.

## Правила

1. Один автор = один файл. Только методы, не пересказ биографии и не пересказ книги целиком.
2. У каждого автора — 1-3 его сильнейших фреймворка/метода.
3. Одна папка = одна область (product, code, business, strategy...).
4. Если метод автора применим в нескольких областях — кладём в основную, в остальных делаем ссылку.
