## Подключение

### Токены (в `.env`, НЕ коммитить)
| Переменная | Назначение | Права |
|-----------|-----------|-------|
| `VK_GROUP_ID=56956529` | ID группы ARclinic | — |
| `VK_ACCESS_TOKEN` | Сервисный ключ приложения | Чтение: wall.get, groups.getById, groups.getMembers |
| `VK_USER_TOKEN` | Community-токен из настроек группы | Запись: wall.post. ⚠️ НЕ умеет wall.delete |

### Ограничения VK API
- **Сервисный токен** — только чтение. `wall.post` и `groups.search` недоступны (ошибки 28, 1051)
- **Community-токен** (создан в `vk.com/arclinic?act=tokens`) — умеет постить, но НЕ удалять (ошибка 27)
- **Для удаления постов** нужен пользовательский токен через OAuth: `https://oauth.vk.com/authorize?client_id=54714418&scope=wall,photos,groups,offline&response_type=token&v=5.199` (не завершено на 10.08.2026)
- `groups.getMembers` — ARclinic скрывает список подписчиков (настройки группы)

### ID приложения
- **App ID:** 54714418 (ARclinic SMM)
- Настройки приложения: `vk.com/editapp?id=54714418` (новый интерфейс VK ID — часть полей недоступна)
