## Воронка продаж

### Этапы
1. **Осведомление** — узнали о клинике (сарафан, поиск, соцсети, отзывы)
2. **Изучение** — читают отзывы, смотрят фото врача, сайт (20–40 мин для сегмента 1)
3. **Запись** — звонок/онлайн-запись
4. **Визит** — первичный приём
5. **Процедура/лечение**
6. **Удержание** — повторные визиты, абонементы, наблюдение
7. **Адвокация** — рекомендации подругам («сарафан»)

### Воронка по сегментам

| Сегмент | Путь входа | Ключевой фактор |
|---------|-----------|-----------------|
| Зрелая женщина | Сарафан/отзывы → изучение → запись к врачу | Лояльность годами |
| Менопауза | Поиск → сайт/блог → гинеколог-эндокринолог | Длинное наблюдение |
| Молодая | Instagram/TikTok → акция → первая процедура | Растёт внутри клиники |
| Мужчины | Рекомендация партнёрши → раздел «Для мужчин» | Приватность |
| Осложнения | Поиск по симптому → кейсы → УЗИ → исправление | Суперлояльность |

### Узкие места
- **Лидогенерация:** мало новых лиц на входе
- **Удержание:** часть пациентов уходит к более дешёвым конкурентам
- **Конверсия сайт→запись:** не замерялась системно

## Контент-стратегия

### Эффективность каналов
- **Telegram-канал** — основной контент-канал, даёт клиентов
- **Блог на сайте** — работает на SEO
- **Instagram врачей** — сильный фактор выбора для сегментов 1 и 3
- **Остальное** — присутствие есть, отдача низкая

### Что усиливать
1. Telegram-канал — образовательный контент про anti-age, гормоны, процедуры
2. SEO-блог — статьи под конкретные поисковые запросы (лечение осложнений, ЗГТ в СПб, ботокс для мужчин)
3. Личный бренд — больше контента от врачей (до/после, ответы на вопросы, кейсы)
4. Видео — разборы процедур, ответы на возражения (Rutube / YouTube)

## Ключевые проблемы маркетинга

1. **Лидогенерация:** упор только на сарафан и базу, новые каналы не тестировались
2. **Удержание:** пациенты уходят к более дешёвым конкурентам
3. **Платная реклама:** попытка ВК-рекламы не дала результатов, остальное не тестировали

## Приоритеты для роста

- Запустить системное тестирование Яндекс.Директ + таргет
- Усилить Telegram-канал как основной контент-канал
- Работа с личным брендом врачей (Instagram)
- SEO-блог под конкретные запросы (лечение осложнений, ЗГТ, мужская косметология)
- Целевой маркетинг на мужской сегмент
- Усиление удержания через мессенджер-рассылки
