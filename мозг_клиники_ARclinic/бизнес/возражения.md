# Возражения и работа с ними

## Общие возражения (все сегменты)

| Возражение | Как работаем |
|-----------|-------------|
| «Дорого» | Через ценность: показываем результат до/после, долгосрочный эффект, предлагаем абонементы. Профилактика дешевле лечения. |
| «Больно» | Честно о дискомфорте. Подчёркиваем комфорт процедур, анестезию, современное оборудование. Показываем результаты. |
| «Я боюсь испортить лицо» | Работаем с естественностью, показываем фото «без фильтров», подчёркиваем умеренный подход. Философия «улучшить, не меняя». |
| «А мне точно это надо?» | Диагностика, честный ответ врача. Консультация без обязательств. |
| «Сделаю потом» | Срочность: возрастные изменения не ждут. Чекапы и диагностика: «лучше предупредить, чем лечить». |
| «Везде обманывают» | Доказательная база, сертификаты, регистрационные удостоверения, отзывы. Открытость. |
| «Лучше копить на пластику» | Косметология — менее инвазивная альтернатива с предсказуемым результатом. |

## Возражения по сегментам

### Сегмент 1 — Зрелая женщина (~50%)

| Возражение | Как работаем |
|-----------|-------------|
| «Вдруг будет видно, что я что-то сделала» | Портфолио естественных результатов, философия «улучшить, не меняя» |
| «Я уже разочаровалась в другой клинике» | Гарантия, открытость, консультация без обязательств |
| «Почему петербургская клиника лучше Цюриха/Москвы?» | Показать научную базу, международный опыт Анны, оборудование |
| «Сколько времени займёт восстановление?» | Конкретные сроки. Для ботулотоксина — 1-2 дня. Микродозы для естественного результата |

| Возражение | Как работаем |
|-----------|-------------|

### Сегмент 3 — Молодая женщина (~20%)

### Сегмент 4 — Мужчины (~7%)

## Как работаем с возражениями (методы)

1. **Превентивно через контент** — пост-ответ на частый вопрос. Образовательный контент в Telegram и блоге.
2. **Лично на консультации** — честно, без продаж. Врач не навязывает, а рекомендует.
3. **Отзывы пациентов** — социальное доказательство. Реальные фото до/после без фильтров.
4. **Первый опыт** — консультация без обязательств. Скидка 10% при записи на процедуру в день консультации.
5. **Прозрачность** — показываем упаковку, срок годности, серию препарата перед процедурой.
