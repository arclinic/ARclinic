# Возражения

## Типичные возражения
1. «Дорого» → Показать ценность: профилактика дешевле лечения
2. «Больно/страшно» → Честно о дискомфорте, показать результаты
3. «А мне точно это надо?» → Диагностика, честный ответ врача
4. «Сделаю потом» → Срочность: возрастные изменения не ждут
5. «Везде обманывают» → Доказательная база, сертификаты, отзывы

## Как работаем с возражениями
- Превентивно через контент (пост-ответ на частый вопрос)
- Лично на консультации — честно, без продаж
- Отзывы пациентов как социальное доказательство
