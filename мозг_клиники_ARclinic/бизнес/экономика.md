# Экономика и метрики ARclinic

## Выручка

| Период | Сумма |
|--------|-------|
| Плохой месяц | ~9 млн руб |
| Хороший месяц | ~15 млн руб |
| Средний месяц | ~12 млн руб |

## Структура выручки по сегментам

| Сегмент | Доля аудитории | Вклад в выручку |
|---------|---------------|-----------------|
| 1. Зрелая женщина | ~50% | Ядро выручки, инъекции + аппараты |
| 2. Менопауза | ~20% | Одна из основных продаж, высокий чек |
| 3. Молодая женщина | ~20% | Входной сегмент |
| 4. Мужчины | ~7% | Растущий, целевой для масштабирования |
| 5. Осложнения | ~3% | Нишевый, высокий чек |

## Структура расходов (% от выручки)

| Статья | Доля | Комментарий |
|--------|------|-------------|
| Зарплата с налогами | 37% | Врачи + персонал |
| Аренда здания + оборудования | 21% | Особняк в центре СПб |
| Закупка материалов | 20% | Ботокс, филлеры, косметика, расходники |
| Маркетинг | 1% | Низкая доля — сильное сарафанное радио |
| Прочие расходы | 7% | Администрирование, связь, софт |
| **Итого операционные** | **86%** | |
| **Маржа** | **~14%** | ~1.7 млн от ср. выручки 12 млн |

## Юнит-экономика (требует заполнения)

- CAC (стоимость привлечения) — рассчитать по каналам
- LTV по каждому сегменту — рассчитать
- Средний чек на визит — рассчитать
- Частота визитов в год — рассчитать
- Срок удержания (мес/лет) — рассчитать
- ROMI (рентабельность маркетинга) — рассчитать

## Целевая динамика

- Увеличить долю **сегмента 4 (мужчины)** за счёт целевого маркетинга
- Запустить платные каналы (Яндекс.Директ + таргет) — маркетинг с 1% поднять
- Оптимизировать расходы без снижения качества

## Потоки дохода

1. **Приём в клинике** — основные процедуры, консультации (90%+)
2. **Контент-проекты** — образовательные продукты (планируется)
3. **Партнёрства** — реклама, коллаборации с брендами

## Топ-услуги по выручке

1. Инъекционная косметология (ботулинотерапия, биоревитализация, филлеры)
2. Аппаратная косметология (SMAS-лифтинг, лазерная шлифовка, RF)
3. Гинекология + диагностика
