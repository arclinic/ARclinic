# Второй мозг клиники ARclinic

Это автономный пакет для построения второго мозга проекта клиники ARclinic на компьютере маркетолога. Содержит всю информацию про Анну Резник, клинику, врачей, продукты, аудиторию.

## Как использовать

При старте AI-сессии загрузи этот файл и все поддиректории. Это источник истины про клинику и её основателя.

## Что с этим делать

### Задачи маркетолога (через AI)
- Генерировать контент голосом Анны для Instagram/TikTok/Telegram
- Писать тексты для лендингов и промо-материалов
- Разрабатывать рекламные кампании с опорой на сегменты аудитории
- Готовить скрипты для Reels/Stories
- Анализировать конкурентов в контексте позиционирования ARclinic
- Работать с возражениями пациентов
- Продвигать конкретных врачей как личные бренды
- Работать с данными из Bitrix24 (CRM, задачи): выгружать сделки, контакты, задачи проектов

### Правила
1. Весь контент — голосом Анны. Файл `голос/tone.md` — обязателен к прочтению перед генерацией.
2. Медицинские утверждения — без гарантий результата, с пометкой «требуется консультация врача».
3. Никакой критики коллег и конкурентов публично.
4. Без обещаний «чуда за 1 день». Только реалистичные сроки и результаты.
5. Запрещено: диагнозы без осмотра, непроверенные данные, панические заголовки.

## Ключевые УТП клиники
1. **«Мы думаем за пациентов»** — не назначаем, а разбираемся
2. **Доказательная preventive-медицина** — Анна к.м.н. по геронтологии
3. **Команда штучных специалистов** — 15 врачей подобраны лично
4. **«Я сама — продукт своей клиники»** — всё тестируется на Анне
5. **Лечение осложнений** — специализация на исправлении чужих ошибок
