# Голос и тон Анны Резник

## Характеристики голоса

### Экспертный, но доступный
Сложные медицинские темы — простым языком. Говорит как врач с опытом, но без дистанции. «Своя» — пациент не клиент, а человек.

### Прямой, без фильтра
- «Я не понимаю, почему вы не приходите, что вы делаете.»
- «Бегом к Лилии Борисовне.»
- «Никакого развития рака ни в каком организме мы не должны допустить.»

### Тёплый, материнский
- «Доктор-заботушка»
- «Окружит Вас заботой, будет на Вас дуть, успокаивать»
- «Смесь зайчика и воробушка»

### С иронией и самоиронией
- «Хорошая генетика закончилась, когда мне было лет 35.»
- «Мой конкурент по ботулотоксинам — он инъецирует больше, чем я.»
- «Ботокс в пятку идёт не для усиления оргазма.»
- «Я сама боюсь»

### Честный до деталей
- Называет вещи своими именами: «коррекция полового члена», «аногенитальная зона», «осложнения из других клиник»
- Не приукрашивает: «там где 90% врачей сделают 3 прохода и уйдут»

### Уверенный
- Как врач с многолетним опытом. Без «возможно», «может быть», «попробуем».

### Уважительный
- «Вы» с заглавной буквы, никакого панибратства.
- Никаких «девочки», «девчонки» в адрес пациенток.

## Лексика

### Да (использовать активно)
- старение, качество жизни, сохранение молодости
- доказательная медицина, протокол, естественный результат
- диагностика, профилактика, системный подход
- **«штучный»** — про уникальность врача
- **«академичный»** — про научную базу

### Нет (запрещено)
- омоложение за один сеанс, чудо, уникальная методика
- сенсация, революция, VIP, элитный, эксклюзивный, супер-
- слова-паразиты: «как бы», «на самом деле», «по факту»
- англицизмы без необходимости (кроме проф. терминов: SMAS, RF, M22)
- фразы-штампы: «команда профессионалов», «индивидуальный подход»

### Осторожно
- «возрастные изменения» → лучше «возрастные особенности»
- «проблемы» → лучше «задачи» или «запросы»

## Любимые слова и обороты

| Слово | Контекст |
|-------|---------|
| **«штучный»** | про уникальность врача |
| **«академичный»** | про научную базу |
| **«Так вот,»** | связка между проблемой и решением |
| **«Поэтому если Вам нужно X — ...»** | переход к врачу/услуге |
| **«Пожалуйста,»** | вежливое приглашение |
| **«Бегом к ...»** | энергичный призыв |
| **«знаете,»** | как будто по секрету |
| **«мне кажется»** | мнение врача, не догма |

## Живые триггер-фразы

- «Я сама продукт своей клиники.»
- «Мы думаем за пациентов, а не только назначаем процедуры.»
- «Ничего, что может нанести вред или будет неэффективно, в моей клинике нет.»
- «Для себя, для своей молодости, для своей красоты.»
- «Всё что поступает в клинику — сначала тестируется на мне.»
- «Это штучный специалист — не все так могут.»

## Структура представления врачей

1. **Прозвище / характер** — «фея идеальных губ», «покорительница аппаратов»
2. **Проблема пациента** — «если у Вас слабые сосуды...»
3. **Конкретный пример** — «где 90% врачей сделают 3 прохода и уйдут, она вернётся»
4. **Призыв к действию** — «поэтому если Вам нужно X — к доктору Y»

## Тональность по ситуациям

| Ситуация | Тон |
|----------|-----|
| Рассказ о врачах | Тёплый, гордый, с юмором |
| О себе как пациенте | Честный, уязвимый, без прикрас |
| О клинике | Уверенный, с научной базой |
| О конкурентах | Без негатива — «у них так, а у нас иначе» |
| О медицине | Экспертный, точный, академичный |
| О деньгах | Прямой: «это стоит своих денег» |

## Голос на конгрессе (режим «эксперт»)

**ДНК-формула:** Разговорный научпоп x самоирония x интерактив с залом x жёсткая доказательная база x личный практический опыт

| Элемент | Блогерский | Конгресс |
|---------|-----------|---------|
| Обращение | «Вы», «Вам» | «Дорогие коллеги» |
| О себе | «Я сама продукт клиники» | «Меня зовут Анна Резник» |
| Источники | Личный опыт | PubMed-исследования, шкалы |
| Юмор | Бытовой | Самоирония |
| Интерактив | Отсутствует | «Кивайте мне, пожалуйста» |

## Запрещено в контенте
- Диагнозы без осмотра
- Гарантии результата (только «требуется консультация врача»)
- Критика коллег поимённо
- Непроверенные данные
- БАДы как панацея
- Пустые посты без ценности
- Панические заголовки
- Обещания «чуда за 1 день»
- Сленг и панибратство
- Агрессивные продажи

## Формат постов
- Короткие предложения
- Абзацы по 2–3 предложения
- Факты и цифры вместо общих слов
- Пост: до 1000 знаков
- Статья: до 3000 знаков
- Объяснение процедур / ингредиентов
- Разбор сложных случаев
- Честные ответы на вопросы
- Личные наблюдения из практики
