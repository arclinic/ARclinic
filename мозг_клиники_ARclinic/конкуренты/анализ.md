# Конкуренты ARclinic — Санкт-Петербург

## Прямые конкуренты (премиум, антивозрастная медицина + косметология)

### Клиника «ABIA»
- **Формат:** многопрофильная, хирургия + косметология
- **Цены:** сопоставимы с ARclinic
- **Сильная сторона:** большой штат, пластическая хирургия
- **Слабая сторона:** конвейерный подход, нет персонального бренда основателя
- **Наша отстройка:** индивидуальный подход, «сами тестируем на себе», репутация Анны

### Clinic «Delete» (СПб)
- **Формат:** косметология + дерматология
- **Цены:** выше рынка
- **Сильная сторона:** сильный маркетинг, раскрученный бренд
- **Слабая сторона:** высокая текучка врачей
- **Наша отстройка:** стабильная команда Анны, врачи подобраны лично

### «Медика» (СПб)
- **Формат:** многопрофильный центр
- **Цены:** средний+
- **Сильная сторона:** широкий спектр услуг
- **Слабая сторона:** нет фокуса на антивозрастной медицине
- **Наша отстройка:** нишевая экспертиза в preventive + anti-age

### Институт красоты «Галактика»
- **Формат:** косметология, эстетическая медицина
- **Цены:** премиум
- **Сильная сторона:** локация (центр), долгая история
- **Слабая сторона:** устаревший подход, слабый SMM
- **Наша отстройка:** современная доказательная медицина, сильный контент

## Косвенные конкуренты

- **Частные косметологи** (демпингуют по цене, но нет контроля качества)
- **Сетевые клиники эконом-сегмента** (быстро, дёшево — но риск осложнений)
- **Онлайн-сервисы** (подбор косметолога, агрегаторы)

## Ценовое позиционирование ARclinic

- **Консультация:** 5000–8000 ₽ (бесплатно для первичных)
- **Ботокс (1 ед):** 450–550 ₽
- **Филлеры (1 мл):** 25000–45000 ₽
- **Плазмотерапия:** 12000–18000 ₽
- **Аппаратная косметология:** 15000–35000 ₽

Позиционирование: верхний сегмент, но с обоснованной ценой (экспертиза + безопасность + результат).

## Ключевые отличия ARclinic (для контента и рекламы)

1. **Основатель с научной степенью** — Анна Резник, к.м.н. по геронтологии
2. **Доказательная медицина** — никаких «авторских методик», только протоколы
3. **Лечение осложнений** — специализация на исправлении чужих ошибок
4. **Тестируем на себе** — все процедуры сначала проходят врачи клиники
5. **14 врачей — личный подбор Анны** — не нанимаем по резюме
