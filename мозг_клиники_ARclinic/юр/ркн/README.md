КЛЮЧЕВЫЕ РЕШЕНИЯ
======================================================================

1. СТАТЬЯ 351.1 ТК РФ — НЕ ПРИМЕНЯЕТСЯ
   Клиника обслуживает только взрослых пациентов, нет лицензии на
   педиатрию. Поэтому «сведения о судимости» не выбраны ни в одной цели.

2. СОЦИАЛЬНОЕ ПОЛОЖЕНИЕ — УБРАНО ИЗ ЦЕЛЕЙ 1 И 2
   Не является стандартным реквизитом кадрового/бухучёта в ООО.

3. СКУД — БЕЗ БИОМЕТРИИ
   Используются только карты/брелоки. Распознавания лиц нет.
   Биометрические ПД не выбраны для цели 12.

4. ИНВИТРО — НЕ ТРАНСГРАНИЧНАЯ ПЕРЕДАЧА
   Российская компания, данные не покидают РФ.

5. ПОДБОР ПЕРСОНАЛА — БЕЗ МЕДИЦИНСКИХ ДАННЫХ
   Медосмотр проводится после принятия решения о найме (цель 1), а не
   на этапе отбора соискателей (цель 10).

6. ДАННЫЕ О КВАЛИФИКАЦИИ И СОСТАВЕ СЕМЬИ
   Обрабатываются через пункт «иные персональные данные» в кадровом учёте.
