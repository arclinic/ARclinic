======================================================================
ЦЕЛЬ №13: Иная
======================================================================

ВНИМАНИЕ: Форма РКН позволяет только ОДНУ цель «Иная». Если интерфейс
позволяет создать несколько — разбейте на подцели 13а-13д ниже.
Если только одну — укажите общее описание и объедините галочки из всех
подцелей в один набор (взяв максимум из каждой категории).

ОПИСАНИЕ ДЛЯ ПОЛЯ «ИНАЯ» (если одна цель):
  Оказание медицинских услуг населению, ведение и хранение медицинской
  документации; направление биоматериалов и персональных данных
  пациентов в сторонние лаборатории для проведения медицинских
  исследований; обработка обращений граждан через сайт, мессенджеры и
  социальные сети; идентификация пользователей публичной сети Wi-Fi;
  ведение аналитики посещаемости сайта с использованием метрических
  программ.
