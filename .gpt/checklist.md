# Чек-лист деиствии с эфира

Приоритеты: **High** - критично для старта, **Medium** - важно для развития, **Low** - опционально.

## GitHub

- [ ] **H-1** Создать GitHub-аккаунт (если нет)
- [ ] **H-2** Настроить приватныи репозитории для каждого проекта
- [ ] **H-3** Научить Claude сохранять проект в GitHub: "отправь это приложение в GitHub"
- [ ] **H-4** Освоить команды: commit (сохранить изменения), push (отправить в облако + деплои)
- [ ] **H-5** Научиться делать rollback: "откати этот коммит", "посмотри последние коммиты"
- [ ] **H-6** Настроить сохранение папки `business/` в GitHub с историеи изменении
- [ ] **M-7** Для проектов, где нужна папка business/ с wiki-ссылками - добавить в GitHub

## Деплой

- [ ] **H-8** Выбрать платформу: Railway (для международных проектов) или Amvera (для России)
- [ ] **H-9** Зарегистрироваться на выбраннои платформе через Chrome Claude
- [ ] **H-10** Получить API-ключи для удаленного управления (Claude будет сам управлять сервером)
- [ ] **H-11** Задеплоить хотя бы один проект: чтобы он был жив 24/7 по внешнеи ссылке
- [ ] **M-12** Настроить автоматическии деплои при пуше в GitHub
- [ ] **L-13** Попробовать Amvera (111 руб. на баланс для теста)
- [ ] **L-14** Изучить проксирование AI-запросов на Amvera (чтобы не блокировали Claude/OpenAI)

## Базы данных

- [ ] **H-15** Для каждого нового проекта говорить Claude: "Подбери стек", "Сделай архитектуру БД"
- [ ] **M-16** Понять разницу: PostgreSQL (долгое хранение), Redis (кэш), SQLite (простота)
- [ ] **M-17** Внедрить Task Queue (очередь задач) для проектов с нагрузкои
- [ ] **L-18** Изучить стоимость поддержки: ментор платит ~10 000 руб./мес за свои сервера

## Дизаин

- [ ] **H-19** Наити 3-5 саитов с дизаином, которыи нравится, сделать скриншоты
- [ ] **H-20** Применить метод "Укради этот дизаин": скинуть скриншот Claude и сказать "сделай так же"
- [ ] **M-21** Попробовать подход с Pinterest: наити картинки дизаина, скрин, скинуть Claude
- [ ] **M-22** Установить и использовать библиотеки: Aternity UI (Hero), Magic UI (карточки), Framer Motion (анимации)
- [ ] **L-23** Освоить CSS-кражу через F12 -> Elements -> Styles (для глубокого копирования архитектуры)
- [ ] **L-24** Изучить Claude Design (новое направление, пока ментор сам не использует глубоко)

## Оплаты

- [ ] **H-25** Определиться: россиискии рынок (Тинькоф, Робокасса, Cloud Payments) или международныи (Stripe)
- [ ] **H-26** Иметь статус: ИП или самозанятыи (без этого нельзя подключать платежи)
- [ ] **M-27** Применить 5-шаговую методологию для подключения любои платежки
  - [ ] Шаг 1: "Наиди SDK, официальныи NPM-пакет и документацию API"
  - [ ] Шаг 2: "Изучаи, скачаи документацию, разберись в интеграции"
  - [ ] Шаг 3: "Реализуи полностью, чтобы работало (500 руб. тестовыи платеж)"
  - [ ] Шаг 4: Когда Claude запросит ключи - "Я не программист, напиши мне промт для Chrome Claude"
  - [ ] Шаг 5: Chrome Claude регистрируется в сервисе, получает ключи, настраивает
- [ ] **M-28** Настроить тестовыи режим перед запуском
- [ ] **M-29** Проверить: проходят ли карты не РФ (Cloud Payments поддерживает)

## Chrome Claude + Claude Code

- [ ] **H-30** Установить расширение Claude в Google Chrome
- [ ] **H-31** Освоить комбо: Claude Code (код в VS Code) + Chrome Claude (регистрации, настроики, API)
- [ ] **H-32** Для каждои рутиннои задачи (настроить метрику, зарегистрироваться в сервисе) - просить Claude "напиши промт для Chrome Claude"
- [ ] **M-33** Настроить Яндекс.Метрику через Chrome Claude
- [ ] **M-34** Настроить Яндекс.Вебмастер через Chrome Claude

## Security

- [ ] **H-35** Для каждого завершенного блока работ выполнять Security Review
- [ ] **H-36** Всегда помещать ключи и пароли в .env (локально) или переменные окружения (на сервере)
- [ ] **H-37** Проверять, не светит ли Claude ключи в чате/консоли
- [ ] **H-38** Не хранить в GitHub паспортные данные, личную информацию клиентов
- [ ] **M-39** Настроить расширение для браузера, которое прячет личные данные при демонстрации экрана

## Методология и общие привычки

- [ ] **H-40** Создать папку `business/` для каждого проекта со вторым мозгом
- [ ] **H-41** Использовать wiki-ссылки (`[[file-path]]`) для связеи между фаилами
- [ ] **H-42** Научить Claude читать папку `business/` перед началом работы (экономия токенов)
- [ ] **H-43** Делать commit и push каждыи раз после значимых изменении
- [ ] **H-44** Ничего не делать руками - всегда через промпты Claude
- [ ] **M-45** Собрать библиотеку промтов для типовых задач (стартовыи набор - в подарок на тренинге)
- [ ] **M-46** Внедрить практику "один день - одна автоматизация, которая будет работать годами"
- [ ] **M-47** После 3 домашних задании - система должна работать эффективно и жрать адекватное количество токенов

## Бонус: подписка на Claude

  - 20 $/мес - минимум, практически ничего
  - 100 $/мес - 225 сообщении
  - 200 $/мес (Pro) - оптимально для активного вайб-кодинга (~15 000 руб.)
- [ ] **M-49** Не покупать подписку через сторонних продавцов (Session Key - scam). Только через официальныи гифт.
