## Философия и принципы

- **Главный принцип**: "что ты делаешь сегодня - должно работать каждый день на тебя". Один день упорной работы ради автоматизации, которая будет работать годами.
- **Вайб-кодер не программист**: все задачи решаются через промпты, а не через ручное написание кода.
- **Ничего руками**: никаких ручных настроек серверов, конфигов, API - только промпты Claude.
- **Security Review**: каждый раз после создания функционала проверять безопасность ключей и данных.
- **Второй мозг**: папка `business/` на каждыи проект с wiki-ссылками, чтобы Claude держал контекст без пережора токенов.

## GitHub

- **Что это**: облако для кода, аналог Яндекс.Диска, но умнее (версионность, откаты, история изменений)
- **Безопасность**: код в облаке - компьютер сломался, код цел. Но не хранить паспортные данные и личную информацию.
- **Commit**: сохранение изменений с описанием
- **Push**: отправка в GitHub + деплой
- **Rollback**: ключевая фишка для вайб-кодеров - если Claude натворил дел, просто говоришь "откати этот коммит"
- **Приватные репозитории**: для хранения кода проектов
- **Open Source**: можно делиться готовыми проектами, давать ссылку Claude

## Деплой (Deploy)

- **Зачем**: чтобы проект работал 24/7, а не только когда включен компьютер. Боты, CRM, автоматизации должны быть в облаке.
- **Варианты**:
  - **Railway** (международный): всё в одном - база данных, Redis, удаленное управление через API-ключи. Claude сам управляет сервером, создает базы, деплоит.
  - **Amvera** (российский аналог): для России. Есть проксирование AI-запросов (Claude/OpenAI не блокирует). Бесплатныи тест - 111 руб. на баланс.
- **Удаленное управление**: Claude получает API-ключи и сам бегает на сервер, создает проекты, настраивает.

## Базы данных (4 типа)

1. **PostgreSQL (SQL)** - "морозильник": все хранится надежно и долго, но доступ медленнее.
2. **Redis** - оперативная память для сайта: кэширование, быстрыи доступ к тому, что нужно прямо сейчаc.
3. **SQLite** - для простых проектов, где не нужно много данных.
4. **Task queue (очередь задач)** - для обработки нагрузки: 100 человек нажали - не ляжет сервер, встанет в очередь.

Методология работы: Claude сам выбирает стек, сам разрабатывает архитектуру БД, сам делает миграции. Новичку не надо думать об этом.

## Дизайн (4 подхода)

1. **Скриншот сайта**: заходишь туда, где нравится дизайн, делаешь скриншот, говоришь Claude "укради этот дизайн". Он перетаскивает цвета, логику, палитру, элементы.
2. **Pinterest**: находишь картинки дизайна, скрин, говоришь "сделай такой же как здесь".
3. **CSS-кража**: F12 -> Elements -> Styles, копируешь CSS код понравившегося сайта. Так глубже поднимается архитектура и цвета.
4. **Библиотеки компонентов**: Aternity UI (Hero-секции), Magic UI (карточки), Framer Motion (анимации). Один промт - и дизайн преображен.

Философия дизайна: дизайн должен продавать, а не быть красивым ради красоты. "Умныи дизайн, конвертирующий дизайн". Пользователю плевать на дизайн, ему важна польза.

## Оплаты (2 ветки + методология)

**Ветки**:
- Россия: Тинькоф, Робокасса, Cloud Payments
- Международные: Stripe

**Единая методология (5 шагов)** для любои платeжной системы:
1. Найди SDK, официальный NPM-пакет и документацию API
2. Claude изучает документацию, разбирается в интеграции
3. Реализует полностью: "сделай, чтобы работало"
4. Запрашиваются ключи и доступ
5. Если не понимаешь - просишь Claude написать промт для Chrome Claude, чтобы он настроил все за тебя

Дополнительно: для приема платежей нужно быть ИП или самозанятым.

## Chrome Claude + Claude Code

- **Chrome Claude**: расширение в Google Chrome, работает в браузере. Может ходить по сайтам, искать информацию, заполнять формы, регистрироваться на сервисах.
- **Claude Code**: работает в VS Code, пишет код.
- **Связка**: Chrome Claude делает всю "бумажную" работу (регистрация, получение ключей, настройка сервисов), Claude Code пишет код.
- **Универсальный настройщик**: когда нужно что-то настроить (Яндекс.Метрику, вебмастер, платежную систему) - просишь Claude "напиши промт для Chrome Claude, который это сделает за меня". Копируешь промт, вставляешь - он все делает.

## Методология проектов

- Каждыи проект = отдельная папка `business/` со вторым мозгом.
- Wiki-ссылки (`[[file-path]]`) для связеи между фаилами.
- Папка `business/` заливается в GitHub (можно приватно).
- Claude читает `business/` и держит контекст проекта без лишних токенов.
- Если делать 3 домашних задания - формируется эффективная система, которая жрет адекватное количество токенов.
