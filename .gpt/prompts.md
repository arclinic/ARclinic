# Все промпты из эфира

## Промпты, произнесенные ментором (дословно или близко к тексту)

### 1. Универсальный промт для улучшения дизайна
**Промт**: "Что-то очень некрасиво. Сделай, пожалуйста, красиво."
**Контекст**: Самый лучший промт по мнению ментора. Говорится Claude, когда текущий дизайн не устраивает. После этого можно добавить: "Сделай еще красивее."
**Use case**: Быстрое улучшение внешнего вида без конкретных указаний.

### 2. Промт на кражу дизайна со скриншота
**Промт**: "Укради этот дизайн."
**Контекст**: После того, как сделан скриншот понравившегося сайта. Можно уточнить: "Сделай такой же, как здесь."
**Use case**: Копирование визуального стиля с референсного сайта.

### 3. Промт на выбор платежной системы
**Промт**: "Мне нужна платёжка на сайт. Выбери, короче, я нахожусь в России, у меня пользователи из России, к примеру, да, или я наоборот международный, у меня пользователь международный. Представь топ-10 платёжных систем, которые лучше всего работают."
**Контекст**: Этап выбора платежной системы для проекта. Claude анализирует и предлагает варианты.
**Use case**: Выбор оптимального платежного провайдера.

### 4. Промт на выбор одной платежной системы
**Промт**: "Слушай, а теперь выбери одну, исходя из этого, и объясни, почему. У меня и фактуру про себя. Ну, а если фактура уже в бизнес-папке есть, учитывай наш проект."
**Контекст**: После получения топа из 10 систем - сужение до одной оптимальной.
**Use case**: Принятие решения с обоснованием.

### 5. Промт на интеграцию платежной системы
**Промт**: "Найди SDK, найди официальные пакеты, документацию API у [название системы]. Изучай, скачай документацию, разберись в интеграции. Реализуй полностью, чтобы у меня работало, чтобы вот, ну, 500 рублей мне надо, чтобы прямо работало."
**Контекст**: Ключевои шаг подключения оплаты - Claude ищет SDK, изучает API и реализует интеграцию.
**Use case**: Полная интеграция платежной системы.

### 6. Промт на создание промта для Chrome Claude
**Промт**: "Напиши мне промт, который клод в Google Хроме. Я ничего не понимаю, я всё-таки вайбкодер, братан. Я не программист. Помни это обо мне, да? Напиши мне промт, который клод в Google Хроме... Сделает всё за меня."
**Контекст**: Когда Claude Code завершил интеграцию и запрашивает ключи/доступы. Ученик не понимает, что делать дальше - просит Claude написать промт для Chrome Claude, которыи зарегистрируется в сервисе и настроит всё.
**Use case**: Делегирование "бумажнои" работы Chrome Claude.

### 7. Промт на старт проекта с GitHub
**Промт**: "Дружище, вот это приложение нужно отправить в GitHub."
**Контекст**: После создания MVP (маломальского приложения) - первыи шаг к сохранению кода в облаке.
**Use case**: Инициализация Git-репозитория и первыи коммит.

### 8. Промт на rollback
**Промт**: "Слушай, ты там что-то где-то сломал, посмотри последние свои коммиты, может быть, это там... Слушай, откати назад. Получилась полная фигня."
**Контекст**: После того как Claude натворил дел, сломал код. Проверка последних коммитов и откат до рабочеи версии.
**Use case**: Откат изменений после ошибки.

### 9. Промт на выбор стека технологии
**Промт**: "Вот такой бот, вот такая идея. Подбери стек."
**Контекст**: На старте проекта - Claude сам выбирает технологии для реализации.
**Use case**: Автоматическии выбор стека под задачу.

### 10. Промт на архитектуру базы данных
**Промт**: "Мне, короче, баз данных нужно обратно. Вот тебе задачка, сделай."
**Контекст**: Когда проект требует базы данных. Claude проектирует архитектуру сам.
**Use case**: Создание схемы БД под проект.

**Вариант-уточнение**: "Давай, учитывая наш проект, сделаем архитектуру баз данных."

### 11. Промт на дизайн с библиотеками
**Промт**: "Установи Aternity UI и Magic UI. Полностью перерабатывай дизайн [название проекта/секции] с эффекциями там такими-то."
**Контекст**: Использование готовых UI-библиотек для улучшения дизайна.
**Use case**: Быстрое преображение дизайна через компонентные библиотеки.

### 12. Промт на Security Review
**Промт**: (подразумевается) "Сделай Security Review." / "Проведи security review."
**Контекст**: После создания любого функционала. Проверка утечки ключей, паролеи, безопасности данных.
**Use case**: Аудит безопасности перед деплоем.

### 13. Промт на скрытие данных в прямом эфире
**Промт**: "Слушай, братан, клод-код сделай, подскажи, как мне сделать так, чтобы у меня на прямом эфире, когда клод работает здесь в браузере, не светились никакие личные данные, а всё это было спрятано."
**Контекст**: Вопрос участника о безопасности демонстрации экрана. Claude предлагает расширения для браузера.
**Use case**: Сокрытие чувствительных данных при стримах/демонстрациях.

### 14. Промт на парсинг и мониторинг
**Промт**: (подразумевается) "Создай пост, подключи к чекеру, сохрани URL, дату нарушения, сумму, email и так далее."
**Контекст**: Создание парсера для мониторинга чего-либо (в примере - проверка штрафов на саите).
**Use case**: Создание AI-парсера с сохранением результатов.

### 15. Промт на создание универсального настроищика
**Промт**: "Напиши промт для хром-клода, чтобы он настроил всё за меня, метрику, вебмастер."
**Контекст**: Когда нужно настроить Яндекс.Метрику или Яндекс.Вебмастер для саита.
**Use case**: Автоматическая настройка аналитики и SEO-инструментов.

### 16. Промт-пример для домашнего задания
**Промт**: "Вот задача такая: сделать план."
**Контекст**: Объяснение того, как создается первичныи план проекта.
**Use case**: Создание плана проекта через Claude.

### 17. Промт на стиль Duolingo
**Промт**: "Сделай так же красиво, как в Дуолинго."
**Контекст**: Референс на известныи сервис как образец дизаинов.
**Use case**: Быстрая стилизация под известныи бренд.

## Мои выводы по промптам (применимость к ARclinic)

### Непосредственно применимы:

1. **"Подбери стек"** - применим для выбора технологии под новую функцию клиники (чат-бот, CRM-интеграция, форма записи).
2. **"Архитектура БД"** - при создании новых таблиц в Bitrix24 или внедрении дополнительных систем учета (например, для сеибестоимости услуг).
3. **"Security Review"** - это must-have. Папка business/ уже содержит чувствительные данные о клинике. Нужно регулярно проверять, не утекают ли ключи Bitrix24 API, токены, данные пациентов.
4. **"Напиши промт для Chrome Claude"** - мощныи паттерн. Когда нужно настроить новыи сервис (новыи канал рекламы, новую платежную систему, интеграцию) - делегировать это Chrome Claude.
5. **"Укради этот дизайн"** - при редизаине лендинга клиники, создании новых посадочных страниц.

### Требуют адаптации:

6. **"Сделай красиво"** - работает, но для медцентра нужен сдержанныи, доверительныи дизайн, а не креатив ради креатива.
7. **"Подключи оплату"** - если в ARclinic появятся онлайн-оплаты (сейчас, судя по структуре, используются абонементы и разовые услуги). Применимо для внедрения онлайн-оплаты с самозанятостью/ИП.
8. **"Создай пост, подключи к чекеру"** - можно адаптировать для мониторинга отзывов, проверки контента на саите, парсинга конкурентов.

### Не применимы:

- "Кража CSS" - слишком техническии подход, для медцентра неактуален.
- "Telegram-бот для роя обсуждении" - черныи маркетинг, не соответствует позиционированию клиники.
- 5-шаговая методология оплат - избыточна, если оплата уже настроена через Bitrix24.

### Что взять в план:

- Создать промт-библиотеку для типовых задач ARclinic.
- Внедрить практику "сначала Security Review, потом деплои".
- Для всех новых интеграции использовать шаблон "напиши промт для Chrome Claude, которыи настроит X".
