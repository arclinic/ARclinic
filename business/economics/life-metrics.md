# Live Metrics — живые данные

## Зачем

В файлах business/ цифры протухают. Этот файл — словарь связей: какая метрика откуда берётся.

Вместо хардкода в файлах используется маркер **LIVE**. Когда задаётся вопрос по цифрам, Claude видит метку, идёт в этот файл, получает свежее значение.

## Подключение

Через REST API Битрикс24.

- **Эндпоинт:** `https://arclinic.bitrix24.ru/rest/8913/{токен}/`
- **Токен:** хранить в `B24_TOKEN` в `.env` или переменной окружения, сюда не вставлять
- **Токен:** вебхук (входящий) — создаётся в разделе «Разработчикам» → «Вебхуки» → «Исходящий вебхук (REST API)»
- **Доступные методы:** `crm.deal.list` (сделки), `crm.invoice.list` (счета), `crm.contact.list` (клиенты), `crm.deal.get` (детали сделки), `report.construct` (отчёты)
- **Права:** доступ к CRM, отчётам, контактам (без права на редактирование)
- **Обезличивание:** персональные данные (ФИО, телефон, email) фильтруются на стороне прокси перед передачей

## Метрики

### Выручка за месяц
- **Маркер:** LIVE
- **Источник:** Битрикс24 (CRM) — отчёт «Выручка по услугам» за период
- **Формат:** число + валюта (₽)

### Количество активных клиентов
- **Маркер:** LIVE
- **Источник:** Битрикс24 — количество уникальных клиентов с оплатой в текущем месяце
- **Формат:** число

### Средний чек
- **Маркер:** LIVE
- **Источник:** Выручка за месяц / количество оплаченных визитов (Битрикс24)
- **Формат:** число + валюта (₽)

### Количество новых клиентов
- **Маркер:** LIVE
- **Источник:** Битрикс24 — клиенты с первой оплатой в периоде
- **Формат:** число

### Загрузка врачей (заполненность расписания)
- **Маркер:** LIVE
- **Источник:** _заполнить_ (интеграция с календарём Битрикс24 или внешней системой записи)
- **Формат:** %

### Себестоимость услуг (всего)
- **Маркер:** LIVE
- **Источник:** _заполнить_ (данные из бухгалтерии / облака)
- **Формат:** число + ₽

### Маржа (прибыль)
- **Маркер:** LIVE
- **Источник:** Выручка за месяц − Расходы за месяц (расчётная)
- **Формат:** число + ₽ / %
