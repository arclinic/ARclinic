# Каналы привлечения

## Текущая эффективность

| Канал | Эффективность | Комментарий |
|-------|---------------|-------------|
| **База пациентов + сарафанное радио** | ★★★★★ | Основной драйвер. 50%+ новых клиентов |
| **Telegram-канал клиники (@arclinic1)** | ★★★★ | 1 371 подписчик, образовательный контент |
| **Яндекс (поиск + карты)** | ★★★★ | Ищут по врачу и услуге |
| **Instagram врачей** | ★★★ | Личный бренд врачей — сильный фактор выбора |
| **ПроДокторов / Google Maps / 2GIS** | ★★★ | Отзывы влияют на решение сегмента 1 |
| **Блог на сайте / SEO** | ★★★ | Работает на долгосрочный трафик |
| **ВКонтакте (группа + канал)** | ★★ | Реклама не сработала, органика слабая |
| **Rutube / YouTube / Дзен** | ★★ | Контент есть, отдача пока низкая |
| **Платная реклама (Яндекс.Директ)** | ★ | Не запускали системно |

## Ключевые проблемы
1. **Лидогенерация:** упор только на сарафан и базу, новые каналы не тестировались
2. **Удержание:** пациенты уходят к более дешёвым конкурентам
3. **Платная реклама:** попытка ВК-рекламы не дала результатов, остальное не тестировали

## Приоритеты для роста
- Запустить системное тестирование Яндекс.Директ + таргет
- Усилить Telegram-канал как основной контент-канал
- Работа с личным брендом врачей (Instagram)
- SEO-блог под конкретные запросы (лечение осложнений, ЗГТ и т.д.)
