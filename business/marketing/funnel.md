# Воронка продаж

## Структура воронки

### Этапы
1. **Осведомление** — узнали о клинике (сарафан, поиск, соцсети, отзывы)
2. **Изучение** — читают отзывы, смотрят фото врача, сайт (20–40 мин для сегмента 1)
3. **Запись** — звонок/онлайн-запись
4. **Визит** — первичный приём
5. **Процедура/лечение**
6. **Удержание** — повторные визиты, абонементы, наблюдение
7. **Адвокация** — рекомендации подругам («сарафан»)

### Узкие места
- **Лидогенерация:** мало новых лиц на входе
- **Удержание:** часть пациентов уходит к конкурентам с более низкими ценами
- **Конверсия сайт→запись:** не замерялась системно

## Сегментная воронка

### Сегмент 1 (зрелая женщина)
Вход через сарафан или отзывы → долгое изучение → запись к конкретному врачу → лояльность годами.

### Сегмент 2 (менопауза)
Поиск по запросу → сайт/блог → запись к гинекологу-эндокринологу → диагностика → длинное наблюдение.

### Сегмент 3 (молодая)
Instagram/TikTok → акция/первая процедура → если понравилось → растёт внутри клиники.

### Сегмент 4 (мужчины)
Рекомендация партнёрши → раздел «Для мужчин» → конкретная услуга → при хорошем опыте — постоянный.

### Сегмент 5 (осложнения)
Поиск по симптому → кейсы на сайте → запись → УЗИ → исправление → суперлояльность.

## Метрики для внедрения
- CAC по каналам (сейчас считаем)
- Конверсия сайт → запись
- Retention Rate (1 мес / 6 мес / 12 мес)
- LTV по сегментам
- Средний чек на визит
