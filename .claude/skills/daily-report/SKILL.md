# Daily Report — ARclinic

## Когда использовать

При запросах: «собери отчёт», «сводка за день», «дайджест», «что по цифрам», «как дела в клинике», «ежедневный отчёт», «что сделали сегодня».

## Что делает

Генерирует XLSX-файл с отчётом в `reports/` с двумя листами:

### Лист 1 — Сводка

| Метрика | Значение |
|---------|----------|
| Дата | [текущая дата] |
| Выручка за месяц | LIVE → [[business/economics/life-metrics]] / Выручка за месяц |
| План месяца | [[business/goals/monthly]] |
| Выполнение плана | [%] |
| Средний чек | LIVE → life-metrics / Средний чек |
| Активные клиенты | LIVE → life-metrics / Количество активных клиентов |
| Новые клиенты | LIVE → life-metrics / Количество новых клиентов |
| Загрузка врачей | LIVE → life-metrics / Загрузка врачей |

### Лист 2 — Детали

- Флаги (зелёный/жёлтый/красный)
- Статус фаз из [[plans/]]
- Изменения в git (за сегодня)
- Заметки на сегодня

## Принципы

1. Данные Bitrix24 тянутся через REST API (токен из B24_TOKEN в .env)
2. Если данных нет — пиши «нет данных»
3. XLSX сохраняется с именем `report-YYYY-MM-DD.xlsx`
4. Формат XLSX — через Python openpyxl
5. Отчёт пишется на русском
6. После генерации скажи пользователю: «Отчёт сохранён в reports/report-YYYY-MM-DD.xlsx. Нужно по какому-то пункту детальнее?»
