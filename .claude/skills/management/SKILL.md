# Management — Управленческие инструменты ARclinic

## Когда использовать

При запросах: «назначь задачу», «план на неделю», «что нужно сделать», «контроль выполнения», «протокол встречи», «follow-up», «KPI», «чеклист», «загрузка врачей».

## Что делает

### 1. Планирование задач
- Назначение задач врачам и персоналу с дедлайнами
- Приоритеты (high/medium/low)
- Связь с пациентами / услугами
- Напоминания о просрочках

### 2. Контроль выполнения (checklist'ы)
- Создание чеклистов по процессам (приём пациента, отчётность, обучение)
- Отметка выполнения с датой
- Автоматический подсчёт % выполнения

### 3. Протоколы совещаний
- Фиксация повестки, решений, ответственных, сроков
- Follow-up статус по каждому пункту
- История протоколов по датам

### 4. KPI и трекинг
- Индивидуальные KPI врачей (загрузка, конверсия, средний чек, донаты)
- Командные KPI (выручка, новые пациенты, NPS)
- Динамика по неделям/месяцам

## Формат вывода
- XLSX или Markdown (по запросу)
- XLSX сохраняется в `reports/` с именем `management-YYYY-MM-DD.xlsx`
- Markdown выводится прямо в чат

## Принципы
1. Данные Bitrix24 тянутся через REST API (токен из B24_TOKEN в .env)
2. Если данных нет — пиши «нет данных»
3. Все отчёты на русском
4. После создания протокола спроси: «Отправить участникам в Telegram?»
5. При постановке задачи всегда указывай: ответственного, дедлайн, приоритет
